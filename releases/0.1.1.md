Adds HACS installation and updates for the standalone Emad Dashboard.

The dashboard keeps all 488 Emad device card types and their controls, animations, responsive layouts, Arabic support, and editing interactions. Your saved layout and entity bindings stay in Home Assistant storage.

Add this repository in **HACS → Custom repositories**, with type **Integration**, then download **Emad Dashboard**. Restart Home Assistant and add **Emad Dashboard** under **Settings → Devices & services** if it is not already configured.

Already installed manually? Download the same integration through HACS, restart Home Assistant, and keep the existing Emad Dashboard config entry. No layout migration or frontend replacement is needed.

HACS uses `emad_dashboard.zip`. For manual installation into the Home Assistant configuration directory use `emad_dashboard-0.1.1.zip`. The source archive and SHA-256 checksums are included separately.
